# 🪨📄✂️ Rock Paper Scissors Game (Python)

A command-line Rock Paper Scissors game where you play against the computer.

## Features
- Choose how many rounds to play
- Computer picks randomly
- Live scoreboard after every round
- Final winner announcement
- Input validation (no crashes on wrong input)
- Play again option

## Concepts Used
- Functions
- Dictionaries
- Loops and conditionals
- `random` module
- Input validation with `try/except`

## How to Run
1. Make sure Python 3 is installed.
2. Download `rock_paper_scissors.py`.
3. Open a terminal in the file's folder and run:

```bash
python rock_paper_scissors.py
```

## How to Play
- Enter the number of rounds.
- Type `r` for Rock, `p` for Paper, or `s` for Scissors.
- Rock beats Scissors, Scissors beats Paper, Paper beats Rock.
